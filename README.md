# Full-Stack Web Application (Spring Boot + React)

Полнофункциональное веб-приложение, построенное на стеке Java Spring Boot (бэкенд) и React.js (фронтенд).

## 🛠 Технологический стек

* **Backend:** Java 17, Spring Boot, Spring Data JPA, REST API.
* **Database:** PostgreSQL / MySQL, Hibernate ORM.
* **Frontend:** React.js, JavaScript (ES6+), Axios, HTML5/CSS3.
* **Tools:** Postman, Maven, Git, IntelliJ IDEA.

## 🌟 Ключевой функционал

* Проектирование RESTful API для обработки CRUD-операций.
* Интеграция клиентской части с бэкендом через HTTP-запросы (Axios/Fetch).
* Валидация входящих данных и обработка ошибок на стороне сервера.
* Оптимизированная структура базы данных с каскадными связями.
